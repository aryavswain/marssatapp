Mathematical & Physics Framework

MarsNet-RL combines discrete orbital mechanics simulation with standard Tabular Q-learning to control continuous vertical satellite positioning. The agent operates without long-term tracking memory, making optimization decisions dynamically at each epoch step.

1. Keplerian Environmental Physics

The environment tracks altitude deviations from a chosen reference baseline using a discrete 1D tracking loop. To prevent numerical accumulation explosions during integration, the physics environment uses a velocity damping variable:

$$v_{t+1} = (0.75 \cdot v_t) + a_{decay} + a_{thrust}$$

Where $a_{decay}$ simulates atmospheric density fluxes or gravity anomalies randomly sampled between -3 and 2 km/f², and $a_{thrust}$ represents active corrections applied by the agent.

3. Shaped Penalty Reward Function

To enforce strict station-keeping boundaries, the agent's reward profile utilizes severe progressive step penalties for escaping standard operating limits:

Base Step Reward: R = -( |Error| / 3.0 )

If |Error| < 15 km: R += 30.0 (Target Orbit Lock Bonus)

If |Error| > 45 km: R -= 50.0 (Corridor Breach Penalty)

If |Error| > 120 km: R -= 200.0 (Critical Vector Drift Penalty)
