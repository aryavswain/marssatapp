System Architecture & Components

The MarsNet-RL architecture is built using modular, highly specialized front-end components and back-end services. WebGL dynamic state streaming keeps telemetry high-performing and accurate.

🌐

WebGL 3D Orbit Canvas

Powered by Plotly.js WebGL rendering. Employs optimized array streams for real-time marker recoloring and size adjustments. Prograde or Retrograde engine burns update visual indicators natively on the GPU without costly DOM redraws.

⚡

Flask Telemetry API

A lightweight Python backend orchestrating asynchronous state handshakes. Handles POST updates from dashboard sliders, passes matrix arrays to calculations, coordinates collision evaluations, and serves training logs instantly via clean JSON outputs.

🤖

Groq AI Mission Copilot

An embedded natural language side-panel interface connected to Groq endpoints running llama-3.3-70b-versatile. Provides real-time context-aware feedback about telemetry anomalies, orbital mechanics, and Q-value optimization trends.

📊

Convergence Charts

A secondary analytics panel that updates reward curves and maximum Q-values across active training epochs. Gives developers a clear look at agent stability and path convergence trends.
