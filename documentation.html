Operations Manual & Quick Start

Follow this documentation guide to deploy, initialize, and tune the reinforcement learning satellite tracking dashboard environment locally.

1. Environment Setup

Install the python core dependencies using pip:

pip install flask groq numpy pandas plotly

Ensure your API credentials are initialized properly inside your terminal framework environment prior to startup:

export GROQ_API_KEY="your_actual_api_key_here"
python app_3.py

2. Mission Control Control Interface

  • Initialize Autonomous Routing: Starts live dashboard iterations and updates the data tables.
  • Online Training Toggle: Enables immediate, runtime adjustment weights so the agent learns actively while processing frames.
  • Refresh Configuration: Instantly updates structural values like total satellites, target altitudes, and payload masses without breaking current WebGL view angles.

3. Agent Parameter Optimization

Developers can optimize convergence behavior inside QLearningAgent by adjusting core parameters:

Learning Rate (α)

Default: 0.1

Determines the update weight applied to new tracking rewards.

Discount Factor (γ)

Default: 0.95

Determines the priority weight placed on long-term future stability.

Epsilon Decay

Default: 0.996

Controls how quickly the agent shifts from random actions to target optimization rules.
